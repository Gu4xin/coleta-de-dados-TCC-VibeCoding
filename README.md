Este repositório reúne os projetos desenvolvidos durante uma pesquisa sobre Vibe Coding, realizada como parte do meu Trabalho de Conclusão de Curso (TCC).

A pesquisa consiste no desenvolvimento de um pequeno site, de baixa complexidade (utilizando primariamente HTML, CSS e JavaScript), utilizando duas abordagens distintas:

- Desenvolvimento sem auxílio de Inteligência Artificial.
- Desenvolvimento com auxílio de Inteligência Artificial.

O objetivo do estudo é analisar o comportamento de estudantes no uso de ferramentas de Inteligência Artificial, buscando compreender os impactos do uso dessas ferramentas no processo de aprendizagem, especialmente no desenvolvimento de habilidades e conhecimentos relacionados à programação.
